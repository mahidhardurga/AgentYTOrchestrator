1Agent settings

Step 10.25 day

Set the model, tools and permissions on the existing agent. Every change here creates a new saved version.

What to create or configure

  • Model: Claude Sonnet 5.5 with effort high. Try Claude Opus 5.5 later in Step 18.
  • Tools: keep the built-in toolset, turn on web search and page reading only for the trusted sites, and give no tool that can deliver content.
  • Permission policy: always_allow for the toolset, because the workspace is locked down and holds no secrets.
  • Description and metadata for easy identification.
  • Record the agent ID and the new version number.
import os, anthropic
client = anthropic.Anthropic()                   # ANTHROPIC_API_KEY from the vault
AGENT_ID = os.environ["CONTENT_AGENT_ID"]
SITES = ["news.example.com", "docs.example.com"]   # trusted sites, bare hostnames

current = client.beta.agents.retrieve(AGENT_ID)
agent = client.beta.agents.update(
    AGENT_ID,
    version=current.version,        # stops us overwriting someone else's edit
    description="Writes three drafts per run from the topic brief, with sources.",
    model={"id": "claude-sonnet-5-5", "effort": "high"},
    system=open("agent/system.md").read(),
    tools=[{
        "type": "agent_toolset_20260401",
        "default_config": {"enabled": True,
                           "permission_policy": {"type": "always_allow"}},
        "configs": [
            {"name": "web_search", "enabled": True, "allowed_domains": SITES},
            {"name": "web_fetch",  "enabled": True, "allowed_domains": SITES,
             "max_content_tokens": 50000},
        ],
    }],
    metadata={"project": "content-writer", "team": "comms"},
)
print(agent.id, agent.version)      # store both in the project settings

ToolSettingWhy

  • Plain hostnames only, no https://, no paths, no wildcards.
  • A listed domain also covers its subdomains. List the bare domain.
  • Between 1 and 64 entries, no duplicates, no IP addresses.
  • The same sites must also be allowed in the environment (Step 2), or the web tools return nothing.
  • Optional: pin where the model runs with "inference_geo": "us" inside the model object, if data location rules require it.
Check it: agent.version increased by one, and a test run (Step 7) shows web search returning results only from the listed sites.

2Environment (the locked workspace)

Step 20.25 day

The environment decides what the agent's workspace can reach. Keep it as small as possible.

What to create or configure

  • One environment named content-writer-env with limited networking.
  • Allowed hosts: every trusted site, listed with and without www.
  • No package installs, no outside tool servers.
  • Save the environment ID.
HOSTS = ["news.example.com", "www.news.example.com",
         "docs.example.com", "www.docs.example.com"]

env = client.beta.environments.create(
    name="content-writer-env",
    config={"type": "cloud",
            "networking": {"type": "limited",
                           "allowed_hosts": HOSTS,
                           "allow_package_managers": False,
                           "allow_mcp_servers": False}},
)
print(env.id)

In the environment list, a bare hostname matches only that exact host: example.com does not match www.example.com. A wildcard such as *.example.com matches every subdomain but not the bare domain. With limited networking, this list also controls the two web tools, so it must include every site in the agent's list.

Check it: a session using this environment can fetch a listed site and fails on any other site.

  • Keep it short and stable. Style and topics belong in memory, so they can change without a new agent version.
  • Re-apply with Step 1 whenever it changes.

You write internal content for <TEAM NAME>. Each run you write three draft items

6Checklist (the outcome and grader)

Step 60.5 day

The checklist is how a separate grader scores each run and sends weak drafts back for fixing before any person sees them.

What to create or configure

  • Write agent/rubric.md from the text below.
  • Start every run with a "define outcome" event holding the task, the checklist and a retry limit of 4.
  • Handle each result: satisfied goes to review normally. max_iterations_reached and failed still go to review, flagged "checklist not fully met".
  • Refine the checklist during Step 18 using real misses.
# Checklist
Grade the files in /mnt/session/outputs/ against every item. Fail the item if
you cannot confirm it from the files.
1. drafts.json and sources.json exist and follow the agreed formats.
2. There are exactly three drafts and their openings differ in style.
3. Each draft is between 900 and 1300 characters.
4. Each draft opens with one specific claim, not a greeting or a question about the reader.
5. Every factual claim points to a source id that exists in sources.json.
6. Every source has an https link, a date and an exact quote.
7. No phrase from brief/off-limits.md appears in any draft.
8. Tone, person and sentence length match voice/style-guide.md.
9. Each draft contains one concrete example, number or short story.
10. Each draft ends with one question or one takeaway, never both.
11. The topic does not appear in history/.

9Checks (plain code, no AI)

Step 90.5 day

Before a reviewer sees anything, our code checks every file the agent produced.

What to create or configure

  • Schema check for both files.
  • Quote check: open each source and confirm the quote appears.
  • Claim mapping: every claim's source id exists.
  • Length check, sensitive-data scan, off-limits phrase scan.
  • Return one report. Anything that fails is shown to the reviewer, not hidden.
# service/checks.py
import os, re
from urllib.parse import urlparse
import requests

ALLOWED = [s.strip().lower() for s in os.environ["ALLOWED_SITES"].split(",")]

def host_ok(url):
    u = urlparse(url)
    h = (u.hostname or "").lower()
    return u.scheme == "https" and any(h == s or h.endswith("." + s) for s in ALLOWED)

def fetch_text(url, hops=3):
    for _ in range(hops):
        if not host_ok(url):
            return None                      # never fetch outside the trusted list
        r = requests.get(url, timeout=15, allow_redirects=False, stream=True,
                         headers={"User-Agent": "content-writer-check"})
        if r.is_redirect:
            url = r.headers.get("location", "")
            continue
        body = r.raw.read(2_000_000, decode_content=True).decode("utf-8", "ignore")
        text = re.sub(r"<(script|style).*?</\1>", " ", body, flags=re.S | re.I)
        return norm(re.sub(r"<[^>]+>", " ", text))
    return None

def norm(s):
    s = s.replace("\u2019", "'").replace("\u201c", '"').replace("\u201d", '"')
    s = s.replace("\u2013", "-").replace("\u2014", "-")
    return re.sub(r"\s+", " ", s).strip().lower()

SENSITIVE = [
    re.compile(r"[\w.+-]+@[\w-]+\.[\w.-]+"),                         # email address
    re.compile(r"\b(?:\d[ -]?){13,16}\b"),                            # card-like number
    re.compile(r"(?i)\b(api[_-]?key|secret|password|token)\b\s*[:=]\s*\S+"),
]

def check_all(drafts, sources, off_limits, lo=900, hi=1300):
    report = {"quotes_failed": [], "claims_unmapped": [], "length": [],
              "sensitive": [], "off_limits": []}
    ids = {s["id"] for s in sources}
    for s in sources:
        page = fetch_text(s["url"])
        if page is None or norm(s["quote"]) not in page:
            report["quotes_failed"].append(s["id"])
    for d in drafts["drafts"]:
        n = len(d["text"])
        if not lo <= n <= hi: report["length"].append((d["id"], n))
        for c in d["claims"]:
            if c["source_id"] not in ids: report["claims_unmapped"].append((d["id"], c["claim"]))
        if any(p.search(d["text"]) for p in SENSITIVE): report["sensitive"].append(d["id"])
        low = d["text"].lower()
        if any(p.lower() in low for p in off_limits): report["off_limits"].append(d["id"])
    report["ok"] = not any(report[k] for k in report if k != "ok")
    return report

The quote check only fetches over https from the trusted list, follows at most three redirects, and each redirect must also be on the list. Without this limit, a bad link in the agent's output could make our service fetch an internal address.

Check it: a made-up quote, a missing source, a short draft, an email address in a draft and an off-limits word each appear in the report.

10Notice receiver (hearing when a run finishes)

Step 101 day

Anthropic sends our service a signed message when something happens to a run. This is how we know to start checking.

What to create or configure

  • In the Anthropic console, open Manage, then Webhooks, and add the endpoint: public HTTPS on port 443, ending in /anthropic/webhook.
  • Subscribe to the event types in the table below.
  • Copy the signing secret (shown once) into the vault as ANTHROPIC_WEBHOOK_SIGNING_KEY.
  • Build the endpoint: verify the signature, ignore repeats, then act.
  • Make every handler safe to run twice.
# service/app.py
import os, time
from flask import Flask, request
import anthropic
from state import seen, get_item, create_item, set_status, audit, setting
from checks import check_all
from review import send_for_review
from alerts import alert

client = anthropic.Anthropic()
app = Flask(__name__)

@app.post("/anthropic/webhook")
def anthropic_webhook():
    try:
        event = client.beta.webhooks.unwrap(request.get_data(as_text=True),
                                            headers=dict(request.headers))
    except Exception:
        audit("system", "webhook_bad_signature", None, {})
        return "invalid signature", 400
    if seen(event.id):                       # the same notice can arrive twice
        return "", 204
    kind, rid = event.data.type, event.data.id
    if kind == "session.status_idled":
        handle_idle(rid)
    elif kind == "session.status_terminated":
        handle_terminated(rid)
    elif kind in ("deployment_run.failed", "deployment.paused"):
        alert("high", f"{kind}: {rid}")
    return "", 204

def latest_idle_stop_reason(session_id):
    last = None
    for ev in client.beta.sessions.events.list(session_id):    # oldest first
        if ev.type == "session.status_idle":
            last = ev
    return last.stop_reason.type if last and last.stop_reason else None

def download_outputs(session_id):
    for _ in range(4):                                         # files appear after a delay
        files = {f.filename: f for f in client.beta.files.list(
            scope_id=session_id, betas=["managed-agents-2026-04-01"])}
        if "drafts.json" in files or "no_topic.txt" in files:
            return files
        time.sleep(3)
    return {}

def handle_idle(session_id):
    item = get_item(session_id) or create_item(session_id)
    if item.status not in ("scheduled", "drafting", "revising"):
        return                                  # already handled, ignore the repeat
    if setting("kill_switch") == "on":
        return
    stop = latest_idle_stop_reason(session_id)
    if stop == "budget_reached":
        set_status(item, "failed", "paused at spending cap")
        alert("high", f"Run {session_id} paused at its spending cap"); return
    if stop == "requires_action":
        alert("high", f"Run {session_id} is waiting for a tool approval"); return
    set_status(item, "checking")
    files = download_outputs(session_id)
    if "no_topic.txt" in files:
        set_status(item, "skipped", "no suitable topic"); return
    drafts, sources = load_and_validate(files)          # schema check from Step 5
    report = check_all(drafts, sources, load_off_limits())
    send_for_review(item, drafts, sources, report, latest_outcome_result(session_id))
    set_status(item, "awaiting_review")

def handle_terminated(session_id):

# service/delivery.py
def deliver_if_allowed(item):
    checks = [
        (setting("kill_switch") != "on",                 "stop switch is on"),
        (setting("delivery_enabled") == "on",             "delivery is off (trial mode)"),
        (item.status == "approved",                       "item is not approved"),
        (item.delivered_at is None,                       "already delivered"),
        (age_hours(item.approved_at) <= int(setting("approval_expiry_hours")),
                                                          "approval expired"),
        (delivered_this_week() < int(setting("max_items_per_week")),
                                                          "weekly limit reached"),
        (inside_window(setting("delivery_window")),       "outside the delivery window"),
    ]
    for ok, why in checks:
        if not ok:
            audit("system", "delivery_blocked", item.id, {"reason": why})
            return False
    text = draft_text(item, item.approved_draft)
    if hashlib.sha256(text.encode()).hexdigest() != item.approved_hash:
        audit("system", "delivery_blocked", item.id, {"reason": "text changed"})
        return False
    ref = DESTINATIONS[item.team](text)             # one function per destination
    item.delivered_to, item.delivered_at, item.delivery_ref = item.team, now(), ref
    set_status(item, "delivered")
    audit("system", "delivered", item.id, {"ref": ref})
    write_history(item, "delivered"); write_feedback(item)
    return True

# service/memory_writeback.py
def write_history(item, outcome):
    path = f"/history/{today()}-{slug(item.topic)}.md"
    body = f"Topic: {item.topic}\nDate: {today()}\nOutcome: {outcome}\n"
    put(path, body)

def write_feedback(item):
    path = f"/feedback/{today()}-{slug(item.topic)}.md"
    body = (f"Chosen draft style: {item.approved_style}\n"
            f"Reviewer note: {item.last_note or 'none'}\n"
            f"Edits made by reviewer: {item.edit_summary or 'none'}\n")
    put(path, body)

def put(path, body, n=1):
    try:
        client.beta.memory_stores.memories.create(STORE_ID, path=path, content=body)
    except Exception as e:                       # path already exists (conflict)
        if "conflict" in str(e).lower() and n < 5:
            put(path.replace(".md", f"-{n+1}.md"), body, n + 1)
        else:
            raise

# service/jobs.py
def sweep():
    for run in recent(client.beta.deployment_runs.list(deployment_id=DEPLOYMENT_ID)):
        if run.error:
            alert_once("high", f"Scheduled run failed: {run.error.type}", run.id); continue
        if run.session_id and not get_item(run.session_id):
            create_item(run.session_id)                    # a notice was missed
    for item in items_with_status("scheduled", "drafting", "revising"):
        s = client.beta.sessions.retrieve(item.session_id)
        if s.status == "idle":        handle_idle(item.session_id)
        elif s.status == "terminated": handle_terminated(item.session_id)
        elif minutes_since(item.updated_at) > 45:
            alert_once("medium", f"Run {item.session_id} is taking too long", item.id)
